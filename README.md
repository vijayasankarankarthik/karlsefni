# Karlsefni – Discord Bot (Java)

Karlsefni is a Discord bot written in Java that provides basic utility and moderation commands for a Discord server.  
The project focuses on implementing commonly used bot features in a clear and straightforward way.

## Features
- `!ping` – checks if the bot is active  
- `!help` – shows the list of available commands  
- `!kick @user` – removes a user from the server (permission required)  
- `!ban @user` – bans a user from the server (permission required)  

## Code Structure
The code is organized so that each command is handled in a separate file.  
This keeps the logic easy to follow and allows new commands to be added without changing existing ones.

## Technologies Used
- Java  
- JDA (Java Discord API)
